AEROLITH is a vintage travel poster for an imagined village floating above dawn clouds, with a lighthouse, warm cottages, and a waterfall falling into the mist.

## Run it

With Node 22, copy the included poster to an output directory:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Run `python3 draw.py` to regenerate `entry.png` in the current directory using Python 3 and Pillow, with DejaVuSans-Bold from `/usr/share/fonts/truetype/dejavu/`.

The renderer uses fixed geometry and no network access; the entry point copies the included PNG to `MAKEFUN_OUTPUT_DIR` (or `/output` by default).
